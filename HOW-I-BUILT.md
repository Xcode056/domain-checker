# How I Built This

I built this project to create a simple domain and business-name checker using HTML, CSS, and JavaScript. The user enters a business name or domain, and JavaScript cleans the input before creating the `.com`, `.pk`, and `.com.pk` versions. I used the Google DNS-over-HTTPS endpoint with the Fetch API to check the domains from the browser. I used `async` and `await` together with `Promise.all()` to check multiple domains and wait for their responses. I also added loading and error states so the user gets feedback while the requests are running. When a domain appears to be taken, the application generates alternative business names and checks their domain versions. Finally, I added a note explaining that DNS results are a strong signal but not a guarantee of registration status.
